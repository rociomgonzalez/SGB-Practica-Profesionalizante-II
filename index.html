Sobre el proyecto

Sistema de Gestión de Bodega (SGB)

El Sistema de Gestión de Bodega es un proyecto desarrollado para facilitar la organización y administración de las actividades de una bodega.

Permite registrar y consultar información relacionada con productos, lotes, producción, inventario, ventas, viñedos, recepción de uva y empleados.

Su objetivo es centralizar la información y facilitar el seguimiento de las diferentes actividades.
