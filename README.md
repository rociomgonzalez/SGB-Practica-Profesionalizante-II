# Sistema de Gestión de Bodega (SGB)

## Proyecto – Práctica Profesionalizante II
**Carrera:** Tecnicatura Superior en Desarrollo de Software  
**Año:** 2026

## 1. Descripción del proyecto

El Sistema de Gestión de Bodega (SGB) es una aplicación desarrollada para organizar y administrar las actividades de una bodega. Permite gestionar productos, lotes, producción, stock, ventas, tareas, viñedos, recepción de uvas, empleados y asistencias.

El proyecto busca facilitar el registro, consulta y administración de la información, centralizando las operaciones principales de la bodega.

## 2. Objetivo general

Desarrollar un sistema informático que permita mejorar la organización y el control de los procesos administrativos y productivos de una bodega mediante herramientas digitales.

## 3. Funcionalidades del sistema

- Gestión de productos.
- Administración de lotes.
- Registro y seguimiento de producciones.
- Control de stock.
- Registro de ventas.
- Gestión de tareas.
- Administración de viñedos.
- Registro de recepción de uvas.
- Gestión de empleados.
- Registro de asistencias.
- Generación de reportes.

## 4. Tecnologías utilizadas

- **Frontend:** HTML, CSS y JavaScript.
- **Backend:** Python y Flask.
- **Base de datos:** MySQL.
- **Bot:** Python y Telegram Bot API.
- **Control de versiones:** Git y GitHub.

## 5. Bot de Telegram

El proyecto incluye un asistente virtual desarrollado en Python e integrado con Telegram.

Su función es brindar información y responder consultas relacionadas con el funcionamiento del Sistema de Gestión de Bodega.

El bot permite realizar consultas sobre los distintos módulos del sistema, como productos, stock, producción, ventas, tareas, viñedos y empleados, entre otros.

## 6. Estructura del proyecto

- `frontend/`: contiene la interfaz visual del sistema.
- `backend/`: contiene la aplicación Flask y la conexión con la base de datos.
- `SGB_Telegram_Bot/`: contiene el código del asistente virtual de Telegram.

## 7. Ejecución del proyecto

Para ejecutar el sistema se requiere:

- Python instalado.
- MySQL instalado y configurado.
- Las dependencias indicadas en los archivos `requirements.txt`.
- Las variables de entorno configuradas localmente.

El backend se ejecuta mediante Flask y el frontend se puede visualizar utilizando un servidor HTTP local.

El bot se ejecuta de manera independiente y requiere configurar su token de Telegram mediante una variable de entorno.
